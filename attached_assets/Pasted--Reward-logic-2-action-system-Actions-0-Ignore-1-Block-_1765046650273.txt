
Reward logic (2-action system)

Actions:

0 = Ignore

1 = Block

Reward rules:

If action == 0 (Ignore):

if true_label == 0 → reward = +10 (correctly ignored normal traffic)

if true_label == 1 → reward = -10 (ignored an attack, security breach)

If action == 1 (Block):

if true_label == 1 → reward = +8 (correctly blocked an attack)

if true_label == 0 → reward = -5 (blocked normal traffic, user impact)
