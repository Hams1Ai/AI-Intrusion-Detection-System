# AI Intrusion Detection System

An AI-powered Intrusion Detection System developed during my cooperative training.

## Overview
This project combines Machine Learning and Reinforcement Learning to detect network intrusions and assist SOC analysts through an interactive dashboard.

## Features
- XGBoost-based attack classification
- Reinforcement Learning (PPO)
- Interactive cybersecurity dashboard
- Risk assessment visualization
- Decision support for SOC analysts

## Technologies
- Python
- XGBoost
- RL
- Scikit-learn
- Stable-Baselines3
- HTML
- CSS
- JavaScript
